# Black Myth: Wukong Automated Benchmark Runner (C#)

Инструмент для автоматического проведения двухпроходного бенчмаркинга (CPU-bound и GPU-bound) игры Black Myth: Wukong Benchmark Tool из Steam.

## Требования
- ОС: Windows 10/11 x64
- .NET 8.0 SDK или новее
- Установленный и авторизованный Steam с загруженным `Black Myth: Wukong Benchmark Tool` (AppID: 3132990)

## Запуск
1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/your-username/wukong-benchmark-runner.git]
   cd wukong-benchmark-runner
